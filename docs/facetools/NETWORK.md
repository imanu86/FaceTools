# Network / cloud printing

FaceTools does not modify the Bambu network plug-in, account handling, TLS, signature checks or protocols, and does not ship the proprietary plug-in. On a cloud-connected printer, *Send* may work but direct *Print* is restricted by Bambu to authorised software and fails with an "unsigned software" warning for this fork. No bypass is attempted or supported; use the printer's own screen to start a sent file, or Bambu's documented LAN/Developer mode at your own risk.
